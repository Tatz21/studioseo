```bash
npm run dev

# Build for production
npm run build
```

## 🎯 Core Features
1. **Real-time On-Page & Technical SEO Auditor:** Meta tags, OpenGraph, Twitter Cards, Canonical links, structured data validation.
2. **Interactive Health Score & Issue Action Center:** Filter issues by 🔴 Critical, 🟡 Warnings, 🟢 Passed, with code snippets.
3. **Google SERP & Social Card Simulator:** Live Desktop vs. Mobile search snippet preview with Facebook and Twitter cards.
4. **Heading Hierarchy & Keyword Density Matrix:** Visual $H_1-H_6$ tree and 1-gram / 2-gram / 3-gram term density calculator.
5. **Schema.org JSON-LD Generator:** Interactive form for LocalBusiness, Organization, Article, Product, and FAQPage.
6. **Robots.txt & Sitemap Tester:** Test crawler paths against user-agent directives.
7. **Export Options:** Download standalone HTML reports, raw JSON datasets, or print to PDF.
